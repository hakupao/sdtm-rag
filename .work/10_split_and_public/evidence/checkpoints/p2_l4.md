## Open risks / decisions to confirm
- **Custom base URL (`X-LLM-Api-Base`) is not offered.** Providers with `base_fixed:false` (private `custom`) are filtered out, so the header is never sent. This matches PLAN §5 ("一期不做 自定义地址"). A private-tier custom-endpoint UI needs a later unit.
- **The web checkbox is greyed from local state** (`tier==="public"` and no active BYOK). It does not use `/api/info.quota.byok`, because the key is not sent to `/api/info`. The server's downgrade remains the authority either way.
- **BYOK models carry no `verified` flag** in `providers[].models`. While BYOK is active, the "反捏造边界未验证" warning is always shown (the conservative choice).
- **String `detail` on non-2xx now reads `服务错误 N: <detail>`** instead of `服务错误 N` (the contract says to show the string). Other shapes are unchanged.
- **The key is plain text in localStorage** (per the contract). Any XSS on the origin could read it. The existing DOMPurify plus CSP are the mitigation; include this in the 2.9 security review.
