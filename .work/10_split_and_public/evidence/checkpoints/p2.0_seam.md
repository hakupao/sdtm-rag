## 出站清单摘要 (详表 design §1)
9 个调用点, 全部经 `server/outbound.py`: Router completion (`/api/ask` 答题/续写/重答)、Router 流 (`/api/ask_stream`, 含工具轮与窄重试)、Tavily、判库 `light`、embedding (每次 retrieve)、HyDE/multiquery (生产 OFF)、validate 审查 `hard`、compare ×N、judge。唯一不经接缝: Cohere rerank (生产 OFF)。

## 接缝要点
- `@request_scope` 建 ctx + 绑 ContextVar; router.py 显式传 ctx, 深层 (rag/federation/reviewer/compare) 用 `current()`; eval/scripts 下为 None, 钩子放行。
- `providers.resolve` 返回 (callable, kwargs) —— 探针第 3 条要求 BYOK 能绕开 Router fallbacks。
- L2 生命周期: `admit(ctx, body)` (检索与拼 prompt 前, 可就地裁 `body.history`) → 每次出站 `h = reserve(ctx, purpose, kw)` / `settle(ctx, purpose, h, usage, model)` → `finalize(ctx)` 恰一次 (非流式在装饰器 finally, 流式在 `finalizing()` 包装, 含客户端断开)。访客身份 / settings 从 `ctx.request` 取。
- `ServiceRefusal` (HTTPException 子类) 在 15 处兜底 except 前先 re-raise (router 9 / rag 4 / federation 1 / reviewer 1); 开流后 (gen 外层) 转 `error` 事件带 code; 联网拒绝转既有 `quota_exceeded`。
- v1 不新增 SSE 事件名 (`test_sse_contract` 约束); 降级/额度挂在 `sources` / `done` / `error` 的新键上, 只在有值时出现。

## 开放问题
1. Cohere rerank 不经接缝 —— L3 公开档启动期拒 `rerank_enabled=true`, 或 L1 接进 outbound。
2. key 进日志的风险: `exc_info=True` + rich traceback 打印帧局部变量, `outbound.*` 帧的 `kw` 将含 `api_key` —— L1 (2.6) 必须在日志层脱敏并用故意报错测试证明。
3. compare / validate 的钩子拒绝会被各自的"单模型失败隔离"/"审查降级 WARN" 吞成槽位错误 (validate 审查已改为 re-raise; compare 槽位仍吞)。两者公开档不注册, 私有档影响小; 若私有档也要限额需 v1.1。
4. 流在客户端断开时 `_metered` 的 `settle` 依赖异步生成器回收, 可能晚到 —— L2 以 `finalize` 为准结算。
5. 契约 §2.3 的 code 表、§2.6 公开档去掉哪些 `/api/info` 键, 由 L1/L2/L3 实现时落定; 增删 code = v1.1, 需同步 L4。
6. 未在派单范围: 研读包 (dossier) 路径没有进特征测试 (需要研究数据); 其调用点与 `/api/ask` 主循环共用同一 `outbound.completion` 行, 已由既有 `test_router_dossier_gate` 全绿覆盖。
