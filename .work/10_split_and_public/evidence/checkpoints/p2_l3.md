## Decisions
- `instance: Literal["private","public"]` (`SDTM_RAG_INSTANCE`, default private). Private = byte-identical (characterization golden unchanged, not regenerated).
- "Force-off + refuse" semantics: on public the four study switches (`config.PUBLIC_FORCED_OFF`) **default** to off (model_validator,
  only for fields not in `model_fields_set`); an operator who explicitly sets one on (kwarg or env) gets a **startup refusal**, not a silent override.
- `instance.check_startup(s)` runs first in `create_app` (so `app = create_app()` at import fails = uvicorn won't start). Public refuses:
  any study switch on, `pdf_context_enabled` (study PDF channel), `rerank_enabled` (Cohere bypasses the seam — §1 open item closed this way),
  any study path existing (`data_dir/study`, `study_kb_root`, catalog, aliases, dossier docs/cards), dogfood log not under `data_dir`.
- New `data_dir_override` / `data_dir` property; `dogfood_log_path` default now `data_dir/dogfood_failures.md` (same path when no override).
- Routes: public includes only `instance.PUBLIC_API_PATHS` (allowlist: health/info/ask/ask_stream/flag) ⇒ `/api/validate`, `/api/validate-study`
  (no request_scope — non-registration is its only guard), `/api/ask_compare` → 404. `docs_url/redoc_url/openapi_url=None`.
- `check_request` (public only; None ctx / private pass-through): endpoint ask_compare/validate → 403 (defence in depth); `dossier="on"` → 403
  `not_on_this_tier{feature:dossier}`; `corpus` study|both → 403 `{feature:study_corpus}`; `X-LLM-Api-Base` header → 400 `custom_base_not_allowed`;
  internal group (always, even with provider) or server-key model not in public `selectable_models` → 422 `model_not_allowed{allowed}`.
  BYOK model ids (provider set) are left to L1 `check_model`.
- `/api/info` public = allowlist `top_k, web_search, selectable_models, index_fresh` + `tier:"public"` + hook extras. Dropped incl. `default_model`
  (litellm string) and `hybrid*`/`structured_lookup`/`prompt_guardrail`. **Deviation**: private does NOT get `tier:"private"` (golden covers
  `/api/info`; contract lets L4 treat missing `tier` as private).
