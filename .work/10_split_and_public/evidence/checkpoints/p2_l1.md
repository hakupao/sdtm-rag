## Design decisions
- **Private default identical**: BYOK is on for `tier=public`, and on private only if `settings.byok_enabled`. Off ⇒ headers ignored,
  `/api/info` has no `providers` (golden `info` byte-identical). Off + any BYOK attempt (key header / base header / `provider`) ⇒
  403 `not_on_this_tier` `feature=byok` (never answer a "use my key" request on the server key).
- **BYOK routing**: only purposes `answer`/`continue`/`regen` carry the user key; `route`/`embedding`/`hyde`/`multiquery`/`review`/
  `compare`/`judge`/`web` stay on the server key (L2 meters them). BYOK calls `litellm.completion/acompletion` directly (looked up at
  call time), never the Router (spike #3), with registry `model`, fixed `api_base`, `max_tokens`, `timeout=120`, `num_retries=1`.
  A BYOK answer call with no checked target fails closed (400).
- **Upstream errors**: 401/403 ⇒ `byok_key_invalid` (401); other failures on `answer` ⇒ `byok_provider_error` (502, `upstream_status`),
  fixed text, `from None`. Kept raw: failures with `stream_options` set (router's narrow retry must run) and `continue`/`regen`
  failures (router keeps the partial answer / restores round 1; its responses are generic text, its logs are redacted).
- **Free tier** = public server key: allowed ids = `settings.public_models` (L3) else selectable ids whose model is the registry
  `free_tier_model` (`deepseek/deepseek-v4-pro`, Q3). Anything else incl. internal groups ⇒ 422 `model_not_allowed` + `allowed`.
- **Prices**: existing §9 table first (golden `ask_compare` cost pinned), then registry `price` override / litellm `cost_per_token(price_ref)`
  (handles tiered rows), then litellm by name.
- **Redaction**: processor renders `exc_info` to text (`format_exc_info`, incl. chained causes) *before* scrubbing — the ConsoleRenderer
  would otherwise format the exception itself, past any scrub — then replaces the current request's exact key and generic key shapes
  (`sk-…`/`AIza…` with a left word boundary so `risk-benefit-…` survives, `Bearer …`, `x-api-key:`/`api_key=`/`authorization:`) in every value. Rich tracebacks become plain text.
- **Custom endpoint** (private only): https only, no userinfo / control chars, every DNS answer must be `is_global` and not
  private/loopback/link-local/multicast/reserved/unspecified (Python 3.14 classifies IPv4-mapped, 6to4, NAT64 correctly — pinned by
  the test set); IP pinned via transport (URL host → IP, SNI + Host stay hostname, cert checked against hostname); 3xx refused at the
  transport (OpenAI SDK sets `follow_redirects=True`); foreign hosts refused; `max_retries=0`. Custom caps are conservative (no tools,
  no vision, 32k).
- **BYOK Anthropic cache_control (follow-up decision)**: implemented in `resolve` — when the system prompt carries the dossier layout
  marker (`研読パッケージ】`), the provider is Anthropic with `prompt_cache` and `settings.dossier_prompt_cache` is on (the legacy
  layout also carries the marker, so the kill switch is checked explicitly), the system becomes one block with an ephemeral breakpoint
  (copy; router's list untouched). **Cache-hit measurement deferred to P3** (needs a real paid Anthropic key; forbidden in this line).

## Open risks
- **Decision for orchestrator — `dossier_auto`**: BYOK models auto-attach the dossier on context length alone (>= 400k, threshold has
  no measured basis), bypassing the server opus-only allowlist; server-key models need allowlist AND context. Private-tier only
  (dossier is off on public).
- **Free-tier price**: legacy `cost.py` §9 row for deepseek-v4-pro = $0.435/$0.87 per 1M; litellm 1.88.1 says $1.32/$3.96 (~3x).
  L2's site cap depends on which is right — verify against DeepSeek's price page before P3.
- Contract stretches L4 will meet: 403 `not_on_this_tier` `feature=byok` (BYOK off); 400 `provider_required` (+`allowed`) for an unknown
  provider; 400 `custom_base_not_allowed` also on private (base header with non-custom provider / custom without base / SSRF reject);
  no `providers` key on private while BYOK is off.
- Preset model ids / domestic base URLs come from litellm 1.88.1's table and public docs; none was called live (no paid calls). P3.5 audit.
- `dossier_auto` note fires on every BYOK request with a <400k-context model while the dossier channel is on (private), even when the
  question would not trigger it (capability runs before `decide_dossier`).
- BYOK headers on `/api/ask_compare` / `/api/validate` (private, BYOK on) are ignored — they run on the server key (not BYOK endpoints;
  public does not register them).
- `quota.reserve` receives BYOK kwargs incl. `api_key`/`client` — L2 must not log or persist kw.
- litellm's own stdlib logging / stdout hints are outside structlog; not redacted by this processor (litellm verbose is off by default).
- Rich tracebacks are now plain text in logs (price of redacting exception text).
- `tier` key in `/api/info` is left to L3 (`instance.shape_info`); L1 supplies only `providers`.
