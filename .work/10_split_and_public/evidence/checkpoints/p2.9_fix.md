## Decisions / deviations

- **#1 settle by how the stream ended** (security-review follow-up from the main session): no usage ⇒ normal end = prompt + ⌈1.5×streamed⌉; early close = prompt + max(1.5×streamed, streamed + `quota_abort_buffer_tokens`=4096); upstream exception mid-stream, timeouts, cancellation, unknown open errors = **full reservation**; clear open rejection (HTTP 4xx/5xx except 408/504, or `httpx.ConnectError`) = prompt only, refunded for the router's narrow retry; non-streamed failure = full. Always ≤ reservation. Reversal vs PLAN 2.7 "中断流按预留扣" recorded in contract v1.2.
- **Residual drain math** (`p2.9_runs/drain_math.txt`; DeepSeek v4-pro $1.32/$3.96, public `max_output_tokens=32000`, free pool $3): an early-close abort costs ≥ $0.019 (2k-token prompt) … $0.096 (max 60k-token prompt) ⇒ 159 … 31 aborts drain the pool; each abort also uses a free question (≤ 30/IP/day) ⇒ one IP can burn at most $0.57 … $2.86/day; ≥ 2 IPs needed in the worst case (pre-fix: full $0.206 each ⇒ 15 aborts). Ambiguous upstream failures still charge $0.206 but are not visitor-controlled.
- **#3**: quota keys stay env-only (+ `validate`); promoting to Settings fields would freeze env at Settings construction and break runtime-env kill-switch tests — not "clean".
- **#4 prompt allowance**: `PROMPT_OVERHEAD_TOKENS = 40_000` + `quota_history_max_chars` (1 token/char worst case). Test fixtures' public model now sets `max_output_tokens=32000` (≈ $0.21 ≤ $0.30).
- **#5** `site_busy` = 503 + `Retry-After: 15`; not a quota code in webchat (retry button kept).
- **#10** in-flight slots carry a TTL = `quota_reservation_ttl_s` (finalize may be delayed to GC on disconnect).
- **#13** applies to continuation rounds only; first-round and **regen-round** refusals still return the 4xx/429 (scope kept).
- **#14** single owner = L1 `providers.capability("web_tools")` reading `quota.free_web_allowed` (L2 key); L2 no longer rewrites `body.web`; `done.web_status` = `off` on downgrade (also fixes the no_tool_calling downgrade misreport).
- **#15** BYOK side budget per IP $0.5/day (¼ of $2 ⇒ ≥ 4 IPs to exhaust; fits 30 Tavily searches = $0.48); bad keys 20/IP/day. Counted only for requests with an ASGI scope.
- **#19** pinned DOMPurify **3.4.18** (not 3.5.0: published 2026-11-22, 4 days old, new minor). Provenance in `webchat/vendor/README.md`.
- Settle hook spies in `test_p2_seam_hooks.py` accept `**kw` (v1.2 keyword args) — contract change, not a test hack.
- Pre-existing, not fixed: `tests/test_p2_l2_integration.py::test_private_default_installs_nothing` fails when that file runs **alone** (first `server.config` import inside the env-clearing fixture reloads `.env`); passes in the full suite. Same on `bacd29a`.
