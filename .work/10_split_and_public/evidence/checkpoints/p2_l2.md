## Policy decisions
- Enabled iff `quota_enabled` true, or unset and tier public. Disabled ⇒ all hooks are P2.0 no-ops, no middleware added, no DB file (test `test_every_hook_passes_through_none_and_disabled`, `test_private_default_installs_nothing`; golden unchanged).
- Pessimistic money: `reserve` charges the estimate immediately (`spend + est <= cap` in one SQL UPDATE); `settle` swaps in actual exactly once (open→settled); `finalize`/expiry keep the estimate (open→charged). A reservation whose request never finalizes is therefore already paid; a late settle cannot refund.
- Free request order: kill switch → cap → rate limit → history trim → free count (visitor cookie AND client IP, all-or-nothing), so refusals never burn a question. Free questions get no web (`body.web=False` + `downgrades: free_tier_no_web`).
- BYOK: not counted; rate-limited; server-key side calls (embedding, route…) metered but **never refused by the cap**; Tavily = server-paid ⇒ BYOK per-visitor daily web quota and respects the cap (refusal → existing `quota_exceeded`).
- A call is user-paid iff the request is BYOK and (purpose ∈ answer/continue/regen, or `kw["api_key"] == ctx.credentials.api_key`). **L1 coordination:** L1 must pass the user key in kwargs for any non-answer BYOK purpose, else it is metered as server-key (safe direction).
- Pricing: `cost.estimate_cost` asked per 1M tokens (it rounds to 6 dp ⇒ embeddings priced $0 otherwise); unknown model ⇒ fallback $5/$25 per Mtok, never $0. Router groups mapped to the real model + deployment `max_tokens` via `app.state.settings`. Prompt estimate: 1 token/non-ASCII char, 1/3 per ASCII char.
- History trim: newest-first contiguous, ≤8 msgs and ≤20k chars; a message that does not fit ends the walk (single >20k message ⇒ empty history); leading assistant dropped.
- Body limit: Content-Length up front, chunked bodies counted; `/api/validate*` exempt (not registered on public).
- `CF-Connecting-IP` used only when the socket peer is in `quota_trusted_proxies`.
